## Goal

Check the three items that came into the web-runner with 1.3.73, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- services-sdk 0.1.16 ([#4957](https://github.com/Koniverse/SubWallet-Extension/issues/4957)) — fixes an error that appeared when turning on a network from a chain-list patch.
- Remove the Crowdloans tab ([#4920](https://github.com/Koniverse/SubWallet-Extension/issues/4920)) — crowdloans are deprecated on Polkadot and Kusama since Agile Coretime, so the tab is gone from every platform. Funds from past crowdloans stay locked until their lease expires, so any locked balance from a crowdloan should still be visible somewhere sensible even with the tab removed.
- Earning position on parachain ([#4950](https://github.com/Koniverse/SubWallet-Extension/issues/4950)) — some chains need two arguments for delegationScheduledRequests, which was breaking the earning position lookup.

## Before testing

- An account with an earning position on a parachain that uses delegated staking, to check the position loads.
- Ideally an account that took part in a crowdloan, so the locked funds can be checked after the tab is gone.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
