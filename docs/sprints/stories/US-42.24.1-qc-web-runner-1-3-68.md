## Goal

Check the items that came into the web-runner with 1.3.68, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Transak widget URL ([#4835](https://github.com/Koniverse/SubWallet-Extension/issues/4835)) — the buy flow now gets its widget URL from an API call instead of building it locally. When the API fails the toast reads "Unable to redirect you to the selected supplier at the moment. Try again later".
- NFT ERC-721 import on Rari ([#4625](https://github.com/Koniverse/SubWallet-Extension/issues/4625)) — importing an ERC-721 or ERC-1155 NFT on Rari used to fail with "Failed to import. Incompatible NFT". Not testable any more: Rari Chain shut down in June 2026.
- NFT without tokenOfOwnerByIndex ([#4568](https://github.com/Koniverse/SubWallet-Extension/issues/4568)) — NFTs on contracts that do not implement tokenOfOwnerByIndex are now found through Blockscout instead.

- Locked balance display ([#4708](https://github.com/Koniverse/SubWallet-Extension/issues/4708)) — tapping the Locked field opens a breakdown by lock type: staking (active and inactive), governance, and others. The "others" figure is total locked minus the larger of staking and governance, with a tooltip explaining it. Single account mode expands in place; all-accounts mode shows a per-account breakdown from the info icon.

## Before testing

- An NFT on a contract that does not implement tokenOfOwnerByIndex.
- An account with tokens locked by staking, both active and inactive, and one with nothing locked, for the breakdown checks.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

The Rari NFT checks need no setup — the chain has shut down, so they are skipped. See the note under those AC.

Second run, 2026-09-05 — the locked balance display

- Passed: AC-10 to AC-17, all eight
- No bugs found
- Full report: [report-manual.md](../../tests/test-reports/2026-09/2026-09-05/report-manual.md)

The breakdown opens on the Locked field and splits into staking, governance and others. The staking row matches the staking screen, the "others" figure works out as total locked minus the larger of the two, and the tooltip reads correctly. All-accounts mode shows the per-account breakdown, and an account with nothing locked renders sensibly rather than breaking. Everything holds after an upgrade.

The Governance row reads zero throughout, which is the only result available while OpenGov is unbuilt — the row exists and behaves, but it has no lock to show. When OpenGov ships, that row wants checking again with a real governance lock behind it.

The locked balance display (#4708) shipped in this version but was originally scheduled under 1.3.70 so its Governance row could be checked alongside OpenGov. OpenGov has not been built, so that story was dropped and these checks came back to the version that actually shipped them.
