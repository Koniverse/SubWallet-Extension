## Goal

Check the items that came into the web-runner with 1.3.68, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Transak widget URL ([#4835](https://github.com/Koniverse/SubWallet-Extension/issues/4835)) — the buy flow now gets its widget URL from an API call instead of building it locally. When the API fails the toast reads "Unable to redirect you to the selected supplier at the moment. Try again later".
- NFT ERC-721 import on Rari ([#4625](https://github.com/Koniverse/SubWallet-Extension/issues/4625)) — importing an ERC-721 or ERC-1155 NFT on Rari used to fail with "Failed to import. Incompatible NFT".
- NFT without tokenOfOwnerByIndex ([#4568](https://github.com/Koniverse/SubWallet-Extension/issues/4568)) — NFTs on contracts that do not implement tokenOfOwnerByIndex are now found through Blockscout instead.

Locked balance display ([#4708](https://github.com/Koniverse/SubWallet-Extension/issues/4708)) shipped in this version too, but it is tested in [US-42.24.3](US-42.24.3-qc-web-runner-1-3-70.md) instead. Its breakdown has a Governance row, so it only makes sense to check alongside OpenGov.

## Before testing

- Contract addresses for an ERC-721 and an ERC-1155 NFT on Rari. The ones in the issue: `0x955210590d6de2181844C3F38a3325859a382D55` (ERC-721) and `0x6aF363f70F23CeA22696D87a00794A854Aa2701f` (ERC-1155).
- An NFT on a contract that does not implement tokenOfOwnerByIndex.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
