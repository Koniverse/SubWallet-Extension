## Goal

Check the four items that came into the web-runner with 1.3.72, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Proxy account ([#4725](https://github.com/Koniverse/SubWallet-Extension/issues/4725)) — full support for Polkadot proxy accounts: create, edit and remove a proxy relationship, across the main proxy types (Any, NonTransfer, Governance, Staking, CancelProxy and chain-specific ones), plus the flow for picking a proxy to act through, with warnings about scope, lifetime and revocation.
- chain-list stable v0.2.123 ([#4861](https://github.com/Koniverse/SubWallet-Extension/issues/4861)) — 16 chain-list patches and 6 stable-build items, including a multichain asset for JPYC.
- USDC and stEWT support.
- ParaSpell V5 ([#4908](https://github.com/Koniverse/SubWallet-Extension/issues/4908)) — the XCM library moved up a major version, so every XCM route has to be checked again.

## A note on the USDC and stEWT line

[#2057](https://github.com/Koniverse/SubWallet-Mobile/issues/2057) writes this as "Add support for USDC & stEWT (#639)", but [#639 on SubWallet-Extension](https://github.com/Koniverse/SubWallet-Extension/issues/639) is a 2022 bug about NFTs not showing when a collection spans several pages — nothing to do with tokens. The number almost certainly points at #639 on the SubWallet-ChainList repo instead. Worth confirming with the developer. The check below tests the tokens, since that is what the release line says shipped.

## Before testing

This is the heaviest setup in the whole set, which is what makes it a 13:

- Several accounts, so one can be made a proxy for another.
- Real funds to create proxy relationships on chain — each proxy type has to be set up separately to be tested.
- Enough balance on both ends of an XCM route to check ParaSpell V5.
- USDC and stEWT holdings to check the token display.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

## Things to check

Proxy accounts

- [ ] AC-1: A proxy relationship can be created, and it appears on chain and in the app — Android + iOS fresh
- [ ] AC-2: The main proxy types can each be set up: Any, NonTransfer, Governance, Staking, CancelProxy — Android + iOS fresh
- [ ] AC-3: Acting through a proxy works — pick the proxy, run an action, and the transaction is signed by the proxy on behalf of the main account — Android + iOS fresh
- [ ] AC-4: A NonTransfer proxy is blocked from transferring, and the app says why rather than failing silently — Android + iOS fresh
- [ ] AC-5: Editing and removing a proxy relationship both work — Android + iOS fresh
- [ ] AC-6: The warnings about proxy scope, lifetime and revocation appear and read correctly — Android + iOS fresh
- [ ] AC-7: AC-1 to AC-6 pass on Android + iOS upgrade

chain-list v0.2.123

- [ ] AC-8: Every chain and token added or changed in v0.2.123 appears correctly — Android + iOS fresh
- [ ] AC-9: JPYC shows as a multichain asset across its chains — Android + iOS fresh
- [ ] AC-10: AC-8 and AC-9 pass on Android + iOS upgrade

USDC and stEWT

- [ ] AC-11: USDC shows with the right name, symbol, logo, decimals and balance, and can be sent — Android + iOS fresh
- [ ] AC-12: stEWT shows correctly and can be sent — Android + iOS fresh
- [ ] AC-13: AC-11 and AC-12 pass on Android + iOS upgrade

ParaSpell V5

- [ ] AC-14: XCM transfers still work on the main routes, and the fee shown before sending matches what is actually taken — Android + iOS fresh
- [ ] AC-15: Routes that existed before the upgrade are all still offered — none quietly disappeared — Android + iOS fresh
- [ ] AC-16: AC-14 and AC-15 pass on Android + iOS upgrade

Upgrade specific
