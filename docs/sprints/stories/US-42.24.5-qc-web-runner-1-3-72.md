## Goal

Check the four items that came into the web-runner with 1.3.72, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Proxy account ([#4725](https://github.com/Koniverse/SubWallet-Extension/issues/4725)) — full support for Polkadot proxy accounts: create, edit and remove a proxy relationship across the main proxy types, act through a proxy, and the deposit the chain reserves for each one. The AC below were written from the QC checklist for this feature rather than from the issue text, which describes goals; the checklist covers the screens, the failure messages, how proxies do not inherit from one another, and the deposit arithmetic. Governance voting through a proxy is skipped — Mobile has no governance screen.
- chain-list stable v0.2.123 ([#4861](https://github.com/Koniverse/SubWallet-Extension/issues/4861)) — 22 ChainList issues plus a set of changes written straight into the issue. New networks (Mosaic Chain, Bifrost mainnet and testnet) and new tokens (Metamask USD, USDC and stEWT on Energy Web X, PYUSD0, Kusama Asset Hub stablecoins, WAVE, PR, JPYC as a multichain asset, a price for NIGHT). Seven token symbols renamed and one chain symbol. Seven networks removed. Two new XCM routes. RPC lists trimmed on eight chains. Logos and explorer links. The AC below work through each group.
- USDC and stEWT on Energy Web X — this is [ChainList #639](https://github.com/Koniverse/SubWallet-ChainList/issues/639), one of the entries inside the chain-list update above. See the note below on why the release list makes it look like a separate item.
- ParaSpell V5 ([#4908](https://github.com/Koniverse/SubWallet-Extension/issues/4908)) — the XCM library moved up a major version, so every XCM route has to be checked again.

## The #639 in the release list is a ChainList number, now confirmed

[#2057](https://github.com/Koniverse/SubWallet-Mobile/issues/2057) writes this line as "Add support for USDC & stEWT (#639)", and [#639 on SubWallet-Extension](https://github.com/Koniverse/SubWallet-Extension/issues/639) is a 2022 bug about NFTs not showing when a collection spans several pages — nothing to do with tokens.

Reading [#4861](https://github.com/Koniverse/SubWallet-Extension/issues/4861) settles it: [ChainList #639](https://github.com/Koniverse/SubWallet-ChainList/issues/639) is "[Energy Web X] Add support for USDC & stEWT", and it is one of the entries rolled into this chain-list version. The release line points at the ChainList repo, not this one. Nothing to confirm with the developer any more; the check is AC-24.
## Before testing

- Three funded accounts on Polkadot — call them A, B and C. The cross-over checks need all three, and the deposit checks need A to hold enough for two proxies and B for one.
- The ProxyDepositBase and ProxyDepositFactor values for the network, so the reserved balance can be checked against the arithmetic rather than against itself.
- Accounts of the other kinds too: a unified account, a solo Polkadot account, a watch-only account, and one on EVM or TON, to see what the Manage proxies tab does on each.
- An account with a balance too small to cover a proxy deposit, for the failure case.
- Balance on both ends of an XCM route for ParaSpell V5, plus balance for the two new routes: Polkadot Asset Hub to Energy Web X, and Polkadot Asset Hub to Kusama Asset Hub.
- Holdings of the new tokens where possible: USDC and stEWT on Energy Web X, Metamask USD, PYUSD0, Kusama Asset Hub stablecoins, WAVE, PR and JPYC.
- An account holding one of the renamed tokens from before the upgrade, and one holding assets on a network this version removes.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

Setting up proxy relationships on chain is the slow part. Each one is a real transaction with a real deposit, and the cross-over group needs three of them before any signing can be checked.

## Test notes

- Tested 2026-09-07, 2026-09-08 and 2026-09-09 — Mobile, Android and iOS, fresh install and upgrade
- Passed: 45 of 47 — proxy accounts, chain-list v0.2.123 and ParaSpell V5, on both platforms and both install paths
- Skipped: AC-19, Mobile has no governance screen to vote from; AC-27, Mobile does not support Cardano
- Six bugs, all on the proxy screens and all display problems — the flows themselves work

Four AC were added while the story ran, each because reading the ChainList issue showed the AC written earlier did not cover what had changed: AC-3a for the metadata marking which chains support proxies, AC-35a and AC-35b for the Shibuya paraChainId and the HOLLAR existential deposit, and AC-31a for the removal of Nodle Parachain and Altair, which the seven-network AC did not name.

The Governance bug is worth the developer's attention: BUG-42.24.5-04 lets a Governance proxy be created on Mobile, and AC-19 is skipped because Mobile has no screen that could use it.
