## Goal

Check the one item that came into the web-runner with 1.3.87, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-90.md).

## What is in this version

Update nominator unstaking eras ([#5055](https://github.com/Koniverse/SubWallet-Extension/issues/5055), [PR #5056](https://github.com/Koniverse/SubWallet-Extension/pull/5056)) — the number of eras a nominator waits before an unstake can be withdrawn was out of date for some networks.

The issue body is empty, so the AC below come from what the change does rather than from a spec. If a description is written later, this story has to be re-read against it.

The item is still unticked on the #2057 tracker, so the fix may not have reached the Mobile build yet. Confirm which web-runner version the build carries before starting.

## Before testing

- An account with a nominating position on a network whose unstaking period changed.
- A position already in the unstaking queue, so the remaining time can be read without waiting for a fresh unstake to mature.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

## Things to check

- [ ] AC-1: The unstaking period shown before confirming an unstake matches what the chain actually enforces — Android + iOS fresh
- [ ] AC-2: A position already unstaking shows the right remaining time, counted in the updated eras — Android + iOS fresh
- [ ] AC-3: Withdraw becomes available when the period ends, and not before — Android + iOS fresh
- [ ] AC-4: AC-1 to AC-3 pass on Android + iOS upgrade
- [ ] AC-5: After upgrading, positions that were already unstaking keep the right remaining time and are not reset — both platforms

## Steps

- [ ] TASK-1 — Note the build under test and its web-runner version, and confirm the fix is in it
- [ ] TASK-2 — Android + iOS fresh install: unstake period, remaining time, withdraw timing (AC-1 to AC-3)
- [ ] TASK-3 — Android + iOS upgrade from the previous version: repeat, then check unstaking positions carried over (AC-4, AC-5)
- [ ] TASK-4 — Log any bugs found in the manual test report
