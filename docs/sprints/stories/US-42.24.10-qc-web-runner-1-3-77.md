## Goal

Check the five items that came into the web-runner with 1.3.77, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Proxy improvements ([#4942](https://github.com/Koniverse/SubWallet-Extension/issues/4942)) — wording fixed when a proxy account is used for staking and unstaking, transfer max improved for proxy accounts, and some EVM network types removed from the list of networks that support proxy accounts.
- Multisig improvements ([#4963](https://github.com/Koniverse/SubWallet-Extension/issues/4963)) — the account picker when creating a multisig gets a search box, account type logos, and grouping by type; requests waiting for approval can be filtered by network type.
- PAH to KAH warning popup turned off ([#4954](https://github.com/Koniverse/SubWallet-Extension/issues/4954)) — the popup warned about a fee that is no longer accurate, since the real fee is far lower than the figure it quoted.
- stDOT sunset ([#4968](https://github.com/Koniverse/SubWallet-Extension/issues/4968)) — StellaSwap has shut down stDOT. The staking option is hidden in Earning, the stake more and unstake buttons are disabled or hidden on the position screen, and the position shows as not earning.
- chain-list stable v0.2.126.

## Two issues are not fully done

[#4942](https://github.com/Koniverse/SubWallet-Extension/issues/4942) still has two unticked items — the wording for proxy on stake and unstake, and the transfer max improvement. Both are marked "recheck, the UI is changed". [#4963](https://github.com/Koniverse/SubWallet-Extension/issues/4963) has an unticked item pointing back at #4942. [#4968](https://github.com/Koniverse/SubWallet-Extension/issues/4968) has an unticked optional item about a popup explaining why a stDOT position was unstaked.

So parts of this scope may simply not be in the build. Record what is missing; do not file it as a bug without checking the issue first.

## Before testing

- Proxy accounts set up from 1.3.72, so the improvements can be checked without building them again.
- A multisig account with several signatories and at least one pending request, from 1.3.74.
- An account holding stDOT with an existing position — hard to create now that deposits are disabled, so use an account that already has one.
- Balance on both PAH and KAH to start a transfer between them.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
