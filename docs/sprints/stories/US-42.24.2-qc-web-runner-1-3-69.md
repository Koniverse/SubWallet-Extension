## Goal

Check the chain-list update that came into the web-runner with 1.3.69, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

chain-list stable v0.2.122 ([#4827](https://github.com/Koniverse/SubWallet-Extension/issues/4827)).

This looks like one line in the release list but it is not one change. The issue rolls up 11 chain-list patches, 6 stable-build items, and a set of content and RPC updates. The named ones worth checking:

- Polkadot to Manta Atlantic XCM pairs rolled back in (they had been removed in v0.2.121)
- Multichain asset added for vMANTA
- Explorer link for Subtensor EVM rechecked
- New RPC endpoints for Stable mainnet

The rest are individual chain and token entries listed by chain-list issue number in [#4827](https://github.com/Koniverse/SubWallet-Extension/issues/4827). Each one is a chain or token to open and look at — many places to check, none of them deep.

## Before testing

- Nothing to set up on-chain. This is a display and connectivity check.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
- The chain-list issue list open alongside, to tick off each entry.

## Things to check

- [ ] AC-1: Every chain and token added or changed in v0.2.122 appears correctly — right name, symbol, logo, decimals — Android fresh
- [ ] AC-2: Polkadot to Manta Atlantic XCM pairs are available again and a transfer can be started — Android fresh
- [ ] AC-3: vMANTA shows as a multichain asset across its chains — Android fresh
- [ ] AC-4: The Subtensor EVM explorer link opens the right page — Android fresh
- [ ] AC-5: The Stable mainnet RPCs connect and balances load — Android fresh
- [ ] AC-6: AC-1 to AC-5 pass on Android upgrade
- [ ] AC-7: AC-1 to AC-5 pass on iOS fresh
- [ ] AC-8: AC-1 to AC-5 pass on iOS upgrade
- [ ] AC-9: After upgrading, networks enabled before the upgrade are still enabled and their balances still load — both platforms
