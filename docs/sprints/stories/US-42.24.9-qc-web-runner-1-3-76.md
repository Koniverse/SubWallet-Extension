## Goal

Check the three items that came into the web-runner with 1.3.76, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Network toggle without an API key ([#4972](https://github.com/Koniverse/SubWallet-Extension/issues/4972)) — a network could not be turned on if no Subscan API key had been added, or the key was wrong. It should turn on either way.
- Subnet token name and ID ([#4892](https://github.com/Koniverse/SubWallet-Extension/issues/4892)) — Bittensor subnet tokens now show their name and subnet ID, written as `{subnetId} | {tokenName} {symbol}`, for example `SN64 | Chutes ش`. This has to appear everywhere a subnet token appears — token list, token detail, transfer forms — and search has to work by subnet ID.
- Bittensor root staking ([#4829](https://github.com/Koniverse/SubWallet-Extension/issues/4829)) — Bittensor changed how root staking rewards work in November 2025. Rewards are no longer paid every 360 blocks; they land roughly once a day at a random time. Stakeholders pick between Root Claim, where earned alpha is converted to TAO and paid to the root hotkey, and Alpha Claim, where it stays as alpha on each subnet.

## Before testing

- A Bittensor account with a root stake, and holdings on more than one subnet.
- Patience or a testnet. Rewards land at a random time roughly once a day, so seeing a payout arrive means waiting. The issue says the changes are on devnet and testnet, so using one of those is the faster route — but setting that up is its own job.
- The Subscan API key from 1.3.75 removed, and set to something wrong, to test both failure cases.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

The reward cycle is what makes this a 13. The session can stop and wait.
