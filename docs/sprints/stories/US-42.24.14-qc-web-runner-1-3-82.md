## Goal

Check that Polygon zkEVM has been removed cleanly, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

Note that 1.3.81 is not in [#2057](https://github.com/Koniverse/SubWallet-Mobile/issues/2057) — the list goes from 1.3.80 to 1.3.82.

## What is in this version

Remove Polygon zkEVM ([#5002](https://github.com/Koniverse/SubWallet-Extension/issues/5002)) — Polygon Labs is shutting down Polygon zkEVM Mainnet Beta, so the chain, its tokens, its assets and the code around it are gone.

A removal, so the checks are that it is absent and that nothing else broke on the way out. The interesting case is an account that still holds something on that chain.

## Before testing

- An account that held tokens or NFTs on Polygon zkEVM before the removal, for the upgrade runs. Without one, the most useful check cannot be made.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

## Things to check

- [ ] AC-1: Polygon zkEVM is not in the network list and cannot be enabled — Android + iOS fresh
- [ ] AC-2: Polygon zkEVM tokens do not appear anywhere — token list, send, swap, or anywhere else — Android + iOS fresh
- [ ] AC-3: Other Polygon networks are unaffected and still work — Android + iOS fresh
- [ ] AC-4: AC-1 to AC-3 pass on Android + iOS upgrade
- [ ] AC-5: An account that held assets on Polygon zkEVM opens without error after the upgrade — no crash, no blank screen, no stuck loading — both platforms
- [ ] AC-6: Old Polygon zkEVM transactions in history either display sensibly or are gone, but do not break the history screen — both platforms

## Steps

- [ ] TASK-1 — Note the build under test and its web-runner version
- [ ] TASK-2 — Android + iOS fresh install: confirm the network and its tokens are gone, other Polygon networks fine (AC-1 to AC-3)
- [ ] TASK-3 — Android + iOS upgrade from the previous version, using an account that held assets there (AC-4, AC-5, AC-6)
- [ ] TASK-4 — Log any bugs found in the manual test report
