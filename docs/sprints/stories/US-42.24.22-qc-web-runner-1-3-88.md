## Goal

Check the four items that came into the web-runner with 1.3.88, on Android and iOS, on a fresh install and on an upgrade. The AC were written out on 2026-09-18 from the release note, taking the story from 8 AC to 17 — the chain-list half was missing entirely, and the route removals turned one AC on its head.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-90.md).

## What is in this version

Update ParaSpell API integration to v2 ([#5051](https://github.com/Koniverse/SubWallet-Extension/issues/5051), [PR #5053](https://github.com/Koniverse/SubWallet-Extension/pull/5053)) — the ParaSpell integration moves to the v2 API. The issue body is one line saying the integration has to align with the latest API version.

ParaSpell is what builds XCM transfers, so an API move touches every cross-chain route rather than one screen. That is why this is a 13 and not a 3: the work is running the routes again, confirming fifteen more are gone, and checking two chain-list entries on top.

The release note also carries chain-list stable: PRDCTR as a new substrate chain ([ChainList #708](https://github.com/Koniverse/SubWallet-ChainList/issues/708)), the Bittensor TUSDT symbol changing from `tUSDT` to `TUSDT` ([#707](https://github.com/Koniverse/SubWallet-ChainList/issues/707)), and fifteen XCM routes removed for chains ParaSpell v2 dropped ([#705](https://github.com/Koniverse/SubWallet-ChainList/issues/705)).

That last one matters for how this story is checked. The first draft of the AC said no route that worked before should disappear; the opposite is true here. ParaSpell v2 dropped Moonbeam, Moonriver and Manta, so those routes must be gone from the picker rather than left there to fail.

This is the second ParaSpell move in the programme. [US-42.24.12](US-42.24.12-qc-web-runner-1-3-79.md) covered the move to API v1 in 1.3.79 and passed, and [US-42.24.5](US-42.24.5-qc-web-runner-1-3-72.md) covered the move to ParaSpell V5 before that. The first two checks carry over — the routes still work and the quoted fee matches what is taken — but the third does not: this time some routes are meant to go.

## Before testing

- Balance on both ends of several XCM routes that ParaSpell v2 still serves, covering substrate to substrate and substrate to EVM.
- An account on Moonbeam, Moonriver and Manta, so AC-7 to AC-10 can check that the routes are gone while the chains themselves still work.
- A Bittensor account holding TUSDT, to read the symbol against and to confirm the holding is not doubled after the rename.
- Balance on PRDCTR for a transfer on the new chain.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
