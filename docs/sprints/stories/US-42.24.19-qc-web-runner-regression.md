## Goal

Run the whole wallet once the web-runner is on 1.3.86, to catch anything the per-version checks missed. Android and iOS, fresh install and upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## Why this is its own sub-task

The eighteen version sub-tasks each check only what changed in that version. This one checks that the wallet as a whole still works after eighteen versions of changes land at once. The checklist lives here and only here, so it is written once instead of being copied into eighteen files where the copies would drift apart.

Run it after the version sub-tasks, on a build with the web-runner already at 1.3.86.

## Before testing

- Accounts covering the main types: created in the app, imported by seed phrase, imported by private key, and a watch-only account if the app supports one.
- Balances on several chains — at least one substrate chain, one EVM chain, and Bittensor.
- NFTs on an EVM chain and on Unique Network.
- An existing staking position and an existing earning position.
- A dApp to connect to.
- The previous version installed with data on it, for the upgrade runs.
