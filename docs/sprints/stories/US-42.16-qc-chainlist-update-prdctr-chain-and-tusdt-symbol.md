- Provider / API URL: `wss://chain-external.prdctr.io`
- Block explorer: https://explorer.prdctr.io
- Price ID: `truth-2`
- Token: PRD (PRDCTR), CoinGecko: https://www.coingecko.com/en/coins/prdctr
- Logo: Figma link in the issue
- Testnet: API `wss://chain-external.testnet.prdctr.io`, explorer https://explorer.testnet.prdctr.io/predictor/blocks

**2. TUSDT token symbol fix ([ChainList #707](https://github.com/Koniverse/SubWallet-ChainList/issues/707))**

- Chain: Bittensor
- Contract: `5GjL2MKErF9ocXZBZZFueoWgf8wAnY1gcgLkDMj2bTsAsg6g`
- Current symbol on SubWallet: `tUSDT`
- Requested symbol: `TUSDT`

The TUSDT token itself was already QC'd in [US-42.4](US-42.4-qc-tusdt-on-bittensor.md) — this story only covers the symbol rename, not a re-test of the whole token.
