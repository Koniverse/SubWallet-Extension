## Goal

Check the three items that came into the web-runner with 1.3.84, on Android and iOS, on a fresh install and on an upgrade. The AC were written out on 2026-09-15 from the release note and the issue bodies, taking the story from 12 AC to 23 — the chain-list half in particular, where each of the four entries carries its own metadata to check.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Recommended validators ([#5024](https://github.com/Koniverse/SubWallet-Extension/issues/5024)) — a suggested validator when staking, for both native and subnet staking, on all three platforms.
- Issues after a version upgrade ([#5013](https://github.com/Koniverse/SubWallet-Extension/issues/5013)) — two problems: the confirmation screen when moving a stake to a different validator looked wrong, and the app crashed when the slider was in use on the unstake screen and the user switched account.
- chain-list stable v0.2.129 — four entries: XCM for MYTH between Polkadot Asset Hub and Hydration ([ChainList #301](https://github.com/Koniverse/SubWallet-ChainList/issues/301)), TUSDT on Bittensor ([#699](https://github.com/Koniverse/SubWallet-ChainList/issues/699)), the Cypress token CP on Base Mainnet ([#703](https://github.com/Koniverse/SubWallet-ChainList/issues/703)), and Polkadot Hub EVM as a new chain ([#701](https://github.com/Koniverse/SubWallet-ChainList/issues/701)).

## Before testing

- An account with a native staking position, and one with a subnet staking position, so the suggestion can be checked on both.
- More than one account, to reproduce the crash by switching while the unstake slider is in use.
- Balance on PAH and Hydration for the MYTH XCM route, on both ends so it can be run each way.
- TUSDT on Bittensor and Cypress on Base Mainnet, enough of each to send, since both are listed as transferable.
- Balance on Polkadot Hub EVM for a transfer on the new chain.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.
