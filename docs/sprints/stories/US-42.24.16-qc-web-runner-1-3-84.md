## Goal

Check the three items that came into the web-runner with 1.3.84, on Android and iOS, on a fresh install and on an upgrade.

Parent: [US-42.24](US-42.24-qc-web-runner-1-3-86.md).

## What is in this version

- Recommended validators ([#5024](https://github.com/Koniverse/SubWallet-Extension/issues/5024)) — a suggested validator when staking, for both native and subnet staking, on all three platforms.
- Issues after a version upgrade ([#5013](https://github.com/Koniverse/SubWallet-Extension/issues/5013)) — two problems: the confirmation screen when moving a stake to a different validator looked wrong, and the app crashed when the slider was in use on the unstake screen and the user switched account.
- chain-list stable v0.2.129 — XCM for MYTH between PAH and Hydration, TUSDT on Bittensor, Cypress token, Polkadot Hub EVM.

## Before testing

- An account with a native staking position, and one with a subnet staking position, so the suggestion can be checked on both.
- More than one account, to reproduce the crash by switching while the unstake slider is in use.
- Balance on PAH and Hydration for the MYTH XCM route.
- The previous web-runner version installed, with accounts and data, for the upgrade runs.

## Things to check

Recommended validators

- [ ] AC-1: A recommended validator is suggested when starting native staking, and it can be overridden with a different choice — Android + iOS fresh
- [ ] AC-2: The same for subnet staking — Android + iOS fresh
- [ ] AC-3: AC-1 and AC-2 pass on Android + iOS upgrade

Issues after upgrade

- [ ] AC-4: The confirmation screen for moving a stake to another validator looks right — Android + iOS fresh
- [ ] AC-5: Using the slider on the unstake screen and then switching account does not crash the app — try it several times, since it is a timing bug — Android + iOS fresh
- [ ] AC-6: AC-4 and AC-5 pass on Android + iOS upgrade

chain-list v0.2.129

- [ ] AC-7: MYTH can be sent by XCM between PAH and Hydration — Android + iOS fresh
- [ ] AC-8: TUSDT on Bittensor shows with the right symbol and balance — Android + iOS fresh
- [ ] AC-9: The Cypress token shows correctly — Android + iOS fresh
- [ ] AC-10: Polkadot Hub EVM connects and balances load — Android + iOS fresh
- [ ] AC-11: AC-7 to AC-10 pass on Android + iOS upgrade

Upgrade specific

- [ ] AC-12: After upgrading, existing staking positions are still correct and the app does not hit the crash from #5013 — both platforms
