## E. The pool-withdrawal fix lives only on `web-runner`

`b1e2e4f514` *"feat: update pool slashing"* (tunghp2002, 10-01) fixes Mobile's P1
`BUG-42.24.19-28`. It edits **`extension-base`** — `staking/bonding/utils.ts`, `relayChain.ts`,
`earning-service/handlers/nomination-pool/index.ts` — and adds `getPoolSlashingSpanCount`, which
counts the **pool stash's** slashing spans (`prior.length + 1`), per its own comment.

`api.call.nominationPoolsApi.memberPendingSlash(address)` — a balance — as `withdrawUnbonded`'s
span count, falling back to `historyDepth`. `git merge-base --is-ancestor b1e2e4f514` fails against
both. The only Extension branch that carries it is `koni/dev/issue-4984` (PR #5001), as cherry-pick
`a7a2a8dd4f`, and that PR is blocked on a chain-list PR build.

**Not established:** whether the Extension reproduces the failure. Nobody has tested it. **Not
minted:** a story — there is no scope, only a gap (rule 7). Raised in [W42](../sprints/sprint-2026-W42.md).
